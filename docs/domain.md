# 领域约定

定义节令食品配方、检测证据、标签声明和生产批次之间的放行事件。

聚合对象包括`formula_revision`、`evidence_record`、`label_claim`、`production_lot`。事件类型包括`FORMULA_VERSIONED`、`EVIDENCE_ACCEPTED`、`CLAIM_APPROVED`、`LOT_LOCKED`、`IMPACT_PROPAGATED`。所有发生时间都必须携带时区，版本号从 1 开始递增，基础校验不会改写调用方输入。

## 事件载荷

- `EVIDENCE_ACCEPTED`：载荷还需包含 `method_ref`, `valid_until`。
- `CLAIM_APPROVED`：载荷还需包含 `market_scope`, `evidence_set`。
- `LOT_LOCKED`：载荷还需包含 `formula_version`, `produced_at`。

相同事件标识的业务幂等、冲突隔离和状态推进由上层服务负责；本仓库只定义可稳定交换的基础事实。

## 放行服务语义

`src/formula_claim/service.py` 在契约事件之上落实以下规则：

- 岗位职责分离：研发提出配方（`FORMULA_VERSIONED`），质量确认证据（`EVIDENCE_ACCEPTED`），法规放行声明（`CLAIM_APPROVED`）。同一人不得兼任链路上任意两环，越权岗位直接拒绝。
- 分级证据门槛：低糖、减油类营养声称需要“营养检测 + 试制结果”；药食同源类需要“药食同源依据”；一般风味描述不设强制证据，但仍需法规放行。门槛不满足时逐项列出缺少的证据。
- 批次锁定：`LOT_LOCKED` 把批次钉在指定配方版本上，生产时间须落在该版本的工厂窗口内；后续配方修订只产生新版本，不改写已锁定批次。声明以批准时的配方版本与批准时间为准，不溯及更早锁定或更早生产的批次。
- 声明收窄：收窄地区时只暂停未售包装（按批次与地区记录），已售批次生成通知范围；`IMPACT_PROPAGATED` 逐批记录影响。
- 共享资源：印刷额度与合格原料按工厂建池、多计划共享；确认计划时幂等占用，超出可用量即拒绝并列出缺口，避免重复承诺。
- 文案评估：给定日期与地区输出一批产品允许与拒绝的文案，拒绝时逐条说明（地区超范围、包装暂停、召回、原料变更待评估、批准晚于生产、配方版本不一致、证据缺失/过期/失效）。

## 影响传播

`src/formula_claim/impact.py` 负责后台作业：检测过期、原料变更、召回发生后，按声明依赖关系与批次锁定版本精确定位受影响批次，逐批处理并写入检查点；中断后用同一作业标识恢复，从下一批继续，不重复落事件。
